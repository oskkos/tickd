# backend

**Empty on purpose. Phase 1.**

Kotlin, Gradle, Spring Boot, jOOQ and Flyway all live here from Phase 1 onward — see `CONCEPT.md` §8
for the target layout and §9 for hosting. The directory exists now so Phase 1 does not begin with a
repository reshuffle (`CONCEPT.md` §13).

Phase 0 has no backend at all: the PWA is local-only, Dexie is the source of truth, and there is no
account, no sync and no API. Adding a build file here is a Phase 0 scope violation
(`openspec/specs/build-tooling`).
